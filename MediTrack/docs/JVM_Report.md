# JVM Report

## Class Loader
Loads .class files into memory.

## Runtime Data Areas
- Heap
- Stack
- Method Area
- PC Register

## Execution Engine
Executes bytecode using interpreter/JIT.

## JIT vs Interpreter
Interpreter executes line-by-line.
JIT compiles frequently used bytecode to native code.

## Write Once Run Anywhere
Java bytecode runs on any JVM-supported platform.
